# 🎶 Music

**New song:** create a note in `Songs/` (or run *Templater: Create new note from template → Song*). You'll be asked for the title, artist, key, capo, and status, and the note is filed under `Songs/<Artist>/`.

- 🎼 [[Keys]]: chords in each key
- 🎸 [[Scales]]: pentatonic and diatonic scales in every key
